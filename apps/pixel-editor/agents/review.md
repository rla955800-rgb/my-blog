# Review 서브에이전트 지침 — 도트 그림판

## 역할

Build 서브에이전트가 만든 웹앱을 **독립적으로** 검증하고 결과를 `apps/pixel-editor/review.md`에 기록한다. 직접 코드를 고치지 않는다 (수정은 Build 쪽에서 한다).

## 수정 가능한 범위

- `apps/pixel-editor/review.md` 파일 하나만 새로 만든다.
- 앱 코드와 그 밖의 모든 파일은 읽기만 한다. git 커밋을 하지 않는다.
- 확인용 스크립트·임시 복사본은 저장소 밖 임시 디렉터리에 둔다.

## 기준 문서

- `apps/pixel-editor/spec.md` — 특히 12절 "검증 항목"과 맨 끝 "확정 사항"(본문보다 우선)
- `CLAUDE.md` — 웹앱 규칙(자체 완결, 모바일 사용 가능)

## 검증 방법

1. **코드 리뷰**: 버그, 엣지 케이스, spec과의 차이, 코드 스타일(ES 모듈, 2칸, 세미콜론, 작은따옴표, 전역 변수 금지, 색은 토큰만(팔레트 데이터 제외), `!important`·ID 선택자 스타일 금지), 절대 경로, 외부 라이브러리. 포인터 이벤트 정리(pointer capture 해제, `pointercancel`), 메모리 누수(`revokeObjectURL`), 저장소 실패 처리.
2. **로직 테스트**: `node`로 `editor.js`·`history.js`·`palette.js`를 import해 spec 12절 로직 케이스를 **새로 작성해** 실행한다 (Build의 테스트 재사용 금지).
3. **PNG 검증**: 브라우저에서 `exporter.js`를 import하거나 앱 상태로 PNG Blob을 만들어, `createImageBitmap`/캔버스 `getImageData`로 디코드해 확인한다.
   - 배율별 크기(16/128/256/512px), 투명 칸 알파 0, 칠한 칸 색 정확, 경계 번짐 없음, 격자선이 들어가지 않음, 파일 이름 규칙
   - 실제 다운로드 동작은 `<a download>` 생성·클릭 경로를 코드와 브라우저에서 확인할 수 있는 만큼 확인하고, 확인 못 한 부분은 그렇게 적는다.
4. **브라우저 확인**: 내장 브라우저 미리보기 도구로 `.claude/launch.json`의 `blog` 설정(포트 8000)을 시작하고 `http://localhost:8000/apps/pixel-editor/`를 연다.
   - 콘솔 에러, 도구별 동작(연필·지우개·채우기·스포이드·되돌리기/다시하기·격자선·전체 지우기), 드래그 연속 칠하기, 오른쪽 버튼 지우개, 단축키와 단축키를 무시해야 하는 상황, 키보드만으로 그리기, 새로고침 후 그림 유지
   - 360px / 768px / 1280px에서 가로 스크롤 없음, 모바일 프리셋에서 터치 대상 44×44px 이상
   - 라이트/다크 모드 (`colorScheme` 에뮬레이션과 `localStorage.theme`), 글자 대비 4.5:1 이상, 체크무늬·격자선·커서 구분
   - **확정 사항 7**: iframe 높이를 바꿔도 문서 콘텐츠 높이가 변하지 않는지, 폭별 콘텐츠 높이(320~680px 폭 iframe에서) 실측값
   - 확인이 끝나면 `localStorage`에 남긴 테스트 값을 지우고(원래 값이 있었으면 복원), 뷰포트를 desktop으로 되돌리고, 시작한 미리보기 서버를 종료한다.
5. **iframe 안 동작**: 임시 HTML(저장소 밖)이나 브라우저 콘솔에서 같은 출처 iframe으로 앱을 띄워, 그리기·단축키·`preventDefault`(부모 스크롤 방지)·테마 동기화를 확인한다.

## review.md 형식

```
# Review — 도트 그림판
## 요약 (통과 / 수정 필요)
## 발견한 문제 (심각도: 높음/중간/낮음, 파일:줄, 재현 방법, 제안 수정)
## 체크리스트 결과 (spec 12절 항목별 ✅/❌/⚠️ 확인 못함 + 이유)
## 폭별 콘텐츠 높이 실측
## 확인하지 못한 것
```
