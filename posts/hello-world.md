안녕하세요! 마크다운 파일만으로 글을 쓰는 작은 블로그를 열었습니다.
프레임워크나 빌드 도구 없이 HTML, CSS, JavaScript만으로 만들었어요.

## 어떻게 동작하나요?

브라우저가 `posts` 폴더의 마크다운 파일을 불러와 그 자리에서 HTML로 바꿔 보여줍니다.
그래서 글을 고친 뒤 **새로고침만 하면** 바로 반영됩니다.

## 새 글 추가하기

1. `posts` 폴더에 `my-post.md` 같은 파일을 만듭니다.
2. 파일 맨 위에 제목, 날짜, 태그를 적습니다.
3. `posts/index.json`에 글을 한 줄 등록합니다.

파일 맨 위에는 이렇게 적어요.

```markdown
---
title: 새 글 제목
date: 2026-11-10
tags: 일상, 개발
description: 목록에 보일 한 줄 요약
---
```

`index.json`에는 다음처럼 추가합니다. `slug`는 파일 이름에서 `.md`를 뺀 값이에요.

```json
{ "slug": "my-post", "title": "새 글 제목", "date": "2026-11-10", "tags": ["일상"] }
```

> 오른쪽 위 버튼으로 다크 모드를 켜고 끌 수 있어요. 고른 테마는 다음에 방문할 때도 유지됩니다.

어떤 문법을 쓸 수 있는지는 [마크다운 문법 안내](#/post/markdown-guide) 글에 정리해 두었습니다.
