## 글자 꾸미기

**굵게**, *기울임*, ~~취소선~~, `인라인 코드`를 쓸 수 있습니다.
밑줄을 써서 __굵게__ 또는 _기울임_ 표시를 할 수도 있습니다. snake_case_name 같은 단어는 그대로 둡니다.
\*별표\*를 그대로 보여주고 싶으면 앞에 역슬래시를 붙이세요.

줄 끝에 공백 두 칸을 넣으면  
이렇게 줄이 바뀝니다.

## 코드 블록

```js
const greet = (name) => {
  // 코드 안의 **별표**나 <태그>는 그대로 보입니다
  return `안녕하세요, ${name}님!`;
};
```

```css
.prose pre {
  overflow-x: auto; /* 아주 긴 줄은 이렇게 코드 블록 안에서만 가로로 스크롤됩니다. 페이지 전체는 밀리지 않아요. */
}
```
